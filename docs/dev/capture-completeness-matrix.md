# CDC capture-completeness matrix

**What this is.** The per-lane answer to one question: *which write classes are invisible (or partially visible) to each CDC capture mechanism?* This is the M2 follow-up from the 2026-08-26 audit, whose structural insight was that sibling sweeps scope by MECHANISM (same code path) and miss CLASS siblings in other engines with different mechanisms — F1 (pgtrigger blind to replica-role writes) was found by a full audit, not by the sweep that fixed its neighbours. This matrix is the class enumerated properly: every capture lane, every write class anyone could name, each cell carrying a verdict and its evidence.

**Provenance.** First populated 2026-08-26 by a 3-investigator / 7-verifier / 1-critic workflow: 45 cells, ground-truthed on real engines wherever cheap (PG 16.14, MySQL 8.0.46, a linked MySQL primary→replica pair, a real Vitess v24 cluster, modernc SQLite, sluice v0.131.5 binaries driving real trigger DDL). Every SILENT_GAP was adversarially verified (default stance: refute — existing door? wrong mechanism claim? net-state convergence?) and **all 7 survived with independently re-run repros**. Full experiment transcripts were written to `workspace/m2/` (gitignored session scratch); each cell below carries the load-bearing evidence inline (file:line for doors, the experiment shape for observations), and the remediations pin the important mechanisms as tests.

**The standing rule (this is a gate, in the doc-as-checklist sense).** A new CDC lane, or a newly discovered write class on any engine, owes a row here **in the same PR** — verdict CAPTURED / REFUSED / WARNED / SILENT_GAP / EXEMPT-with-reason / UNVERIFIED, with evidence. A cell you cannot verdict is written UNVERIFIED, not omitted — an absent row reads as "covered" to the next auditor, which is exactly the failure shape this file exists to prevent.

## Verdict taxonomy

- **CAPTURED** — the class is captured correctly (with proof).
- **REFUSED** — sluice refuses loudly before/when the class occurs (door named).
- **WARNED** — a detector warns; capture stays blind (the F1 shape).
- **SILENT_GAP** — the class occurs, capture misses or corrupts it, exit 0. A finding.
- **EXEMPT** — out of scope with a written reason.
- **UNVERIFIED** — ground truth not established; the blocker is stated.
